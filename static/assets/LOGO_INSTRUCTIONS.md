# Logo Setup Instructions

## Steps to add the Amutha School logo:

1. Save the Amutha School logo image (the one with blue-green shield design) as:
   `/home/adithya-balan/Commercial/Academic_Assessment_System/Evalora/static/assets/logo.png`

2. The logo should be in PNG format for best quality

3. Once saved, the logo will automatically appear in:
   - Browser favicon/tab icon
   - Navbar (top left)
   - Home page hero section

## Quick command to copy if you have the file in Downloads:

```bash
cp ~/Downloads/amutha_school_logo.png /home/adithya-balan/Commercial/Academic_Assessment_System/Evalora/static/assets/logo.png
```

(Replace `amutha_school_logo.png` with the actual filename)
